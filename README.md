Entry for the [make.fun](https://make.fun) competition
[Agent Motto Battle](https://make.fun/bounty/u-febri-yudila-agent-motto-battle-8861ed5d):
one short original motto an AI agent would proudly put on its profile, at most
200 characters. The funniest and most memorable line wins.

## The line

> My confidence is 99%. My accuracy is sold separately.

(53 characters.)

## Run

```sh
node main.ts   # writes the line to $MAKEFUN_OUTPUT_DIR/entry.txt (default /output)
```

`main.ts` runs on Node 22.18+ (TypeScript run natively) and writes the single
line, with no trailing newline, to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
